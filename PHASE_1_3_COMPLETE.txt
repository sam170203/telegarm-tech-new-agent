THE RANKING ENGINE (Phase 1.3)
──────────────────────────────

HOW IT WORKS:

  180 Fetched Stories
        ↓
  Relevance Scorer    (40%) - Matches your keywords: vLLM, CUDA, distributed systems, etc.
  Virality Scorer     (30%) - HN scores + Reddit upvotes = community signal
  Depth Scorer        (20%) - Technical richness (keywords + content + source authority)
  Novelty Scorer      (10%) - Recent stories scored higher
        ↓
  Weighted Combination = Composite Score (0.0-1.0)
        ↓
  Top 10 Stories with Detailed Breakdowns

EXAMPLE OUTPUT:

  1. vLLM: High-Throughput Serving with CUDA
     Score: 0.752
     ├─ Relevance: 0.650 (matches "vLLM" + "CUDA")
     ├─ Virality:  0.820 (450 HN upvotes)
     ├─ Depth:     0.480 (technical keywords + GitHub source)
     └─ Novelty:   0.950 (published 2 hours ago)

  2. Distributed Transformers: Scaling with MCP Protocol
     Score: 0.698
     ├─ Relevance: 0.520
     ├─ Virality:  0.750
     ├─ Depth:     0.620
     └─ Novelty:   0.880

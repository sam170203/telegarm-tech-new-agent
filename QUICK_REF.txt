WHAT WAS BUILT

  Phase 1.3: Intelligent Ranking System
  ────────────────────────────────────
  
  Input:  180 fetched & deduplicated stories
  Output: Top 10 ranked by composite score
  
  4-Factor Ranking Algorithm:
  ├─ Relevance (40%)  - Your interest keywords matched
  ├─ Virality (30%)   - Community engagement signals  
  ├─ Depth (20%)      - Technical richness score
  └─ Novelty (10%)    - Recency boost (exponential decay)
  
  Result: Personalized top 10 stories daily

API USAGE

  Basic ranking:
    from app.ranking.manager import RankingManager
    ranker = RankingManager()
    ranked = ranker.rank_stories(stories)  # List of (story, score)
  
  Top N with breakdowns:
    results = ranker.get_ranked_with_scores(stories)
    for item in results[:10]:
      print(item['story'].title)
      print(f"  Score: {item['score']:.3f}")
      print(f"  Breakdown: {item['breakdown']}")
  
  Custom weights:
    from app.ranking.scorer import CompositeScorer
    scorer = CompositeScorer(
      interest_keywords=["vLLM", "CUDA"],
      weight_relevance=0.7,
      weight_virality=0.15,
      weight_depth=0.1,
      weight_novelty=0.05
    )
